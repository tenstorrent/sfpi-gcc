cc-narrowing-writers — audited-narrowing certificate for the raw typed
CC writers admitted into the CC-restore containment fact by
-mtt-tensix-optimize-cc-region-general (FABLE_GOES_BURR R2 widening 1;
gimple-rvtt-invariant.cc cc_narrowing_modifier_p).

OBLIGATION.  A modifier is NARROWING when a lane disabled before the
write is still disabled after it: enable_out subset-of enable_in,
pointwise per lane, for every operand value.  (The containment fact the
invariant pass needs: the enable set at an in-region candidate is a
subset of the region entry's.)

FORM.  This is a STRUCTURAL certificate, not a value sweep: for every
writer below, the pinned simulator computes its per-lane flag decision
strictly inside `for_each_lane (mask)` where
`mask = p_tensix->cc_en ? p_tensix->cc : 0xFFFFFFFF` -- a lane outside
the current enable mask is never visited, so its enable bit cannot
change, for EVERY operand value; the per-lane decision only chooses
between `cc |= bit` and `cc &= ~bit` on visited lanes.  A 2^32 value
sweep would exercise only the visited-lane decision, which the
obligation does not constrain; the disabled-lane case is a two-row
truth table decided by the loop guard.  The certificate is therefore
the file:line audit of that guard per writer.
